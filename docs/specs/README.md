# Specifications

Normative formats and procedures that independent implementations must follow. A specification
implements one or more ADRs in [`../decisions/`](../decisions/README.md); where they conflict, the
accepted ADR and the security invariants take precedence and the spec is corrected.

Conventions: each spec states its status, the ADRs and invariants it implements, every dependency on an
ADR that is not yet accepted, and the error code produced by each check. Each spec ships deterministic
test vectors generated by committed code.
